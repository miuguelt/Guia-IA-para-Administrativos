La práctica de clima utiliza Antigravity para organizar un análisis y revisar sus gráficos. Un artefacto es un resultado del agente, como un plan, un informe o una visualización. Pídele que distinga un boceto de un resultado calculado.

  1. Prepara el proyecto. Descomprime el laboratorio de clima y abre la carpeta en Antigravity. En el IDE, usa el panel del agente; en la aplicación, selecciona el proyecto correspondiente.
  2. Identifica archivos y entorno. Pide al agente listar el CSV, el cuaderno y las instrucciones. Solicita que compruebe si puede ejecutar Python y qué bibliotecas están disponibles. No interpretes una respuesta sobre capacidades como una ejecución realizada.
  3. Solicita el plan. Si está disponible, usa el modo de planificación. La tarea debe incluir revisión del periodo, detección de valores ausentes, agregaciones mensuales y dos gráficos separados para temperatura y precipitación.
  4. Revisa supuestos. La temperatura mensual se obtiene promediando valores diarios válidos; la precipitación acumulada requiere sumar valores diarios y revisar la cobertura. No son la misma operación.
  5. Ejecuta el análisis. Revisa los cambios y las solicitudes de ejecución que presente tu versión. Pide guardar el código y los resultados. Si muestra un gráfico interactivo, confirma que use el archivo incluido y que indique el periodo filtrado.
  6. Prueba los controles. Cambia el mes o el rango de fechas. Verifica que el conteo y la tabla cambien junto con la figura. Solicita foco visible, etiquetas y manejo por teclado.
  7. Exporta y comprueba. Abre el resultado fuera del proyecto, si su formato lo permite. Pide indicar si el HTML funciona sin conexión o necesita bibliotecas o mapas externos.

Jupyter y Colab: observa el análisis por etapas

Consultar conceptos, fuentes y opciones de ampliación

Un cuaderno .ipynb combina texto, código y resultados. El código queda visible: puedes pedir una explicación de una línea, revisar una fórmula y ejecutar de nuevo. No necesitas aprender todas las instrucciones de Python antes de completar una práctica.

  1. Descarga un paquete completo. Lee las primeras celdas del cuaderno para conocer los archivos y dependencias que necesita.
  2. En Colab, abre la opción de subir un cuaderno y selecciona el archivo .ipynb. Carga también los datos en las rutas que indique el cuaderno. Subir el cuaderno no sube automáticamente toda la carpeta del paquete.
  3. Si usas Jupyter, abre la carpeta descomprimida y selecciona el cuaderno. Usa el entorno de Python indicado en sus instrucciones. No instales herramientas duplicadas si el equipo ya tiene un entorno preparado.
  4. Ejecuta las celdas desde arriba. Espera a que termine cada una y lee su salida. Si aparece un error de ruta, comprueba la ubicación del CSV; si falta una biblioteca, revisa la celda de preparación.
  5. Cambia solo un filtro, por ejemplo el país o el mes, y vuelve a ejecutar desde la celda que lo usa. Explica qué resultado esperabas y qué ocurrió.
  6. Reinicia la sesión de cálculo y ejecuta todas las celdas. Guarda el cuaderno ejecutado y descarga resultados. Las sesiones de Colab son temporales; los archivos de su entorno no constituyen un respaldo permanente.

Los cuadernos disponibles son exoplanetas, población, clima y sismos. Consulta las características de Jupyter y los recursos y límites de Colab.

Excel: importa, compara y comprueba

Esta ruta sirve para revisar una tabla sin programar. Conserva el CSV original y trabaja en un libro nuevo. Los nombres de los controles cambian entre versiones, pero la vista previa y los tipos de columna siguen siendo decisiones importantes.

  1. Importa el archivo. En Datos > Desde texto/CSV, selecciona el CSV. Revisa la codificación, el separador y la vista previa; si las tildes se ven mal o todas las columnas quedan juntas, corrige la importación antes de cargar.
  2. Comprueba los tipos. Conserva como texto los códigos con ceros iniciales. Revisa que las fechas y cantidades queden como fechas y números. Compara los encabezados, el total de filas y tres registros con la ficha de procedencia.
  3. Organiza la tabla. Activa filtros para elegir país, año o categoría. Si vas a resumir varios grupos, una tabla dinámica puede ayudar; verifica que la operación sea adecuada. Para población por año, no sumes años como si fueran personas distintas.
  4. Calcula con una regla visible. Para comparar un valor inicial y uno final, usa (final − inicial) / inicial y aplica formato de porcentaje. Si falta un extremo o el inicial es cero, marca el resultado como «no calculable»; no lo reemplaces por cero.
  5. Grafica para responder la pregunta. Usa líneas para una evolución temporal y barras para una comparación acotada. Incluye título, unidades, periodo y fuente. Contrasta un punto o una barra con la fila que la alimenta y entrega también la tabla.
  6. Guarda y deja rastro. Guarda el análisis como un archivo nuevo .xlsx. Anota filtros, fórmulas, fecha de descarga y decisiones sobre ausencias para que otra persona pueda repetirlo.

Si repites la importación, Power Query puede guardar los pasos de transformación. Antes de actualizar, revisa la vista previa, los tipos y la cantidad de filas: repetir un paso no garantiza que esté bien configurado. Consulta la ayuda oficial sobre CSV con codificación UTF-8, importación de archivos de texto y Power Query.

Power BI

Úsalo cuando necesites varias vistas conectadas: una línea de población, barras por país y filtros de año. Importa el CSV, verifica tipos, construye las medidas y revisa cómo se cruzan los filtros. Para el valor de un año, no sumes todos los años. La publicación y la actualización deben comprobarse en tu entorno. Primer informe.

OpenRefine

Úsalo para detectar variantes de nombres en una tabla propia. Crea una faceta de texto, revisa categorías y agrupa propuestas de coincidencia. Antes de unir «San José» con otro nombre parecido, verifica el código territorial. Exporta la tabla limpia y conserva el historial de transformaciones. Manual oficial.

pandas y DuckDB

pandas permite filtrar, unir y resumir tablas desde Python. Cuando reúnes muchos archivos, DuckDB permite consultar columnas y periodos sin convertir el trabajo en una conversación de millones de filas. Parquet organiza los datos por columnas y facilita estas consultas. Comienza con una muestra, pero calcula los resultados finales sobre el universo declarado. pandas y DuckDB y Parquet.

Plotly y Altair

Pide Plotly para explorar puntos con zoom, filtros y detalles; un HTML puede conservar interactividad. Altair permite relacionar selecciones entre varias vistas. Con muchos puntos, solicita agregaciones, transparencias o mapas de densidad y explica qué se está agrupando. Exportación de Plotly y interacciones en Altair.

Matplotlib

Úsalo para una figura que vas a imprimir o incorporar en un informe. Pide resolución suficiente, unidades, etiquetas completas e incertidumbre cuando los datos la incluyan. Exporta SVG o PDF para conservar trazos nítidos y PNG para una vista rápida. Guía oficial.

Entrega accesible: acompaña cada visual con una tabla y una explicación. Usa etiquetas y formas además del color, evita animaciones indispensables y prueba el teclado y el aumento de tamaño. Una persona debe poder entender el resultado aunque no vea el gráfico.
