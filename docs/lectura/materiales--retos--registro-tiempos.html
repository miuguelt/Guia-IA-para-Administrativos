Referencia de campos para la IA

Registro opcional de tiempos · Recurso complementario

Referencia de campos para las actividades de práctica. La IA completa una copia y genera el documento; tú revisas y descargas. Conserva sin cambios los archivos fuente. No incluyas datos personales ni expedientes reales. Recurso opcional de consulta. Si decides comparar tiempos en un piloto, distingue tiempos medidos, estimados y pendientes; usa una referencia manual observada de una tarea equivalente si existe y no repitas el trabajo a mano solo para crearla. Sin referencia comparable, deja el ahorro pendiente.

La IA genera el documento con estos campos y completa una copia del CSV cuando se necesita. Usa el encargo del paquete; revisa el resultado y descarga los archivos. Las mediciones sin respaldo quedan pendientes.
